# Security Policy

## Reporting Security Vulnerabilities

The Intrinsic Core team takes the security of our software and the physical safety of robotic systems seriously. If you believe you have found a security vulnerability in any Intrinsic Core repository, please report it to us responsibly before public disclosure.

&nbsp;

**Please do NOT report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

&nbsp;

---

## How to Report a Vulnerability

You can report security vulnerabilities through the following channel:

### Email Security Intake

Send an email to: 📧 **`security@intrinsic.ai`**

&nbsp;

Please include:

&nbsp;

* A descriptive summary of the vulnerability.  
* The affected repository, branch, and commit hash or release version.  
* Step-by-step instructions or a minimal Proof-of-Concept (PoC) to reproduce the issue.  
* Any known mitigations or suggested patches.

&nbsp;

---

## Response Process

1. **Acknowledgment**: Our security team will acknowledge receipt of your vulnerability report.  
2. **Triage & Verification**: We will validate the issue, determine its severity, and coordinate with the respective squad maintainers.  
3. **Remediation**: Maintainers will develop and test a security fix in a private temporary fork / advisory workspace.  
4. **Coordinated Disclosure**: We follow standard coordinated disclosure process. Once a patch is verified and release packages are ready, we will publish a GitHub Security Advisory and release notes crediting the finder (unless anonymity is requested).&nbsp;
